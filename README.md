# PAISA

Multi-tenant ERP + HRMS + LMS + CRM platform. `server/` = Express 5 + MongoDB, `client/` = React 19 + Vite + RTK Query.

```bash
npm install     # Node >= 20 required
npm run dev     # API on :5000, UI on :5173 (Vite proxies /api)
npm run build
```

Full project context (architecture, roles/permissions, feature state, known bugs, backlog): see [CONTEXT.md](CONTEXT.md).
